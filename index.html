EL MODELO, EN CLARO

De las respuestas
al valor del crédito.

Se promedian las preguntas de cada variable y se combinan según su peso. Ese puntaje define el ajuste sobre la base de tu programa.

VCAP = VBCI × g(x)

01

Puntaje ponderado

x = 0,20 CP + 0,20 C + 0,30 E + 0,30 P

02

Factor de ajuste

Si 1 ≤ x ≤ 3: g(x) = 0,80 + 0,10 × (x − 1)
Si 3 < x ≤ 5: g(x) = 1,00 + 0,75 × (x − 3)

Descuento máximo: 20 %. Incremento máximo: 150 %.
03

Valor por crédito

Se multiplica la base por el factor, sin redondeos intermedios. El resultado se redondea al peso más cercano.
